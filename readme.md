### Final Project Development Roadmap

**Start Date:** Saturday, July 11
**Final Deadline:** Wednesday, July 29

---

# Overall MVP Goal

Build a website where:

- Users can browse GPS and geolocation products
- Users belong to adventure guide communities
- Communities have leaders and members
- Customers can request a guide
- Products can be viewed and purchased
- Community hierarchy is visualized
- Meeting links are generated (mock implementation acceptable initially)
